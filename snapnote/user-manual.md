A modern web-based notes application. All notes are saved locally and fully searchable.

## Quick Start

### New Note
Create a quick note with title and content. Click the **New Note** button in the ribbon to get started.

### Open File
Open an existing markdown or text file. Use the **Open File** button to browse your local files.

### Templates
Use pre-built templates for daily notes, tasks, and more. Access templates via the ribbon once you have notes.

## Features

### Smart Search
Find notes instantly by title, content, or tags. Press `Ctrl + K` to open the Command Palette for quick search.

### OCR Capture
Extract text from images using AI-powered OCR. Available when a note is selected and you're online.

### Tag System
Organize notes with hashtags and filter by tags. Add tags like `#work`, `#ideas`, `#todo` to your notes.

### Smart Filters
Filter by today, this week, recently modified, or untagged. Access these from the sidebar once you have notes.

### Daily Notes
Auto-generated daily note templates with date. Press `Ctrl + Shift + D` to create a daily note instantly.

### Dark Mode
Switch between light and dark themes anytime. Click the sun/moon icon in the top-right corner.

## View & Organization

### List View
Compact list with note details. Best for quickly scanning through many notes.

### Grid View
Card-based layout for overview. Great for visual browsing of your notes.

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + K` | Open Command Palette |
| `Ctrl + Shift + F` | Advanced Search |
| `Ctrl + Shift + D` | Create Daily Note |
| `Esc` | Close dialogs / Go back |

## Smart Filters (Available After Creating Notes)

### Created Today
See all notes created today. Perfect for tracking daily work.

### Created This Week
Review your week's notes and progress.

### Recently Modified
Notes edited in the last 7 days. Quickly jump back to recent work.

### Untagged
Find notes without tags to help organize your collection.

## Getting Started

Click **New Note** or **Open File** in the ribbon above to begin. Once you have notes, the sidebar will show Smart Filters and Tags for quick organization.

---

**Tip:** All your notes are stored locally in your browser. Use the Export feature to create backups or share your notes.
