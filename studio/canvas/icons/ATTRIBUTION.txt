Bundled icon artwork
====================

The SVGs in this directory ship with the studio and feed the Icon Library
panel. They are unmodified apart from the normalisation applied at load time
(a fixed 64x64 intrinsic size and a concrete colour in place of `currentColor`).

`catalog.json` is generated by `sync-icons.mjs` at the project root. It lists
every bundled icon as a `[source, slug]` pair; the app derives the display
name, search keywords and category from the slug. Artwork is fetched per
visible tile rather than parsed at startup.

  Source:  https://www.npmjs.com/package/lucide-static
  Icons:   24x24 stroke artwork, drawn with `stroke="currentColor"`.

  Project: https://simpleicons.org

  Note:    The CC0 dedication covers the SVG files; the marks themselves

bootstrap-icons/ — Bootstrap Icons (2,078 icons)
  Licence: MIT
  Project: https://icons.getbootstrap.com
  Source:  https://www.npmjs.com/package/bootstrap-icons
  Icons:   16x16 solid UI artwork, drawn with `fill="currentColor"`.

No other icon sets are bundled. Vendor sets such as AWS Architecture Icons,
Azure Architecture Icons, Google Cloud icons and Cisco's icon library are
deliberately absent: their terms permit use in diagrams but not redistribution
inside an app.

Re-importing a set
==================

    node sync-icons.mjs

That downloads the current npm tarballs, replaces the set directories and
rewrites `catalog.json`. Bump `CATALOG_VERSION` in the script when the artwork
changes so existing installs drop their stale indexed copies.

Diagram stencils
================

`src/engine/svg/stencils/` converts draw.io mxStencil packs (electrical, P&ID,
floorplan, UI controls, racks, network symbols, integration patterns) into
registry shapes. The XML source and its licence notice live in
`vendor/drawio-stencils/`. Vendor libraries (AWS/Azure/GCP/Cisco/IBM) are not
included there either.
