# Welcome to TextStudio

This is a sample Markdown file to help you get started with TextStudio.

## Features

TextStudio is a writing-focused text editor with these features:

- **Writing Goals**: Set daily word-count targets
- **EPUB Export**: Export your documents as EPUB books
- **Voice Typing**: Dictate your text using the browser's speech recognition
- **Daily Notes**: Quick access to a daily note template
- **Ambient Sounds**: Background sounds to help you focus
- **Wiki Graph**: Visualize connections between your documents

## Markdown Basics

### Headings

Use `#` for main headings, `##` for subheadings, and so on.

### Lists

- Unordered lists use `-` or `*`
- Ordered lists use numbers

1. First item
2. Second item
3. Third item

### Code

Inline code uses backticks: `const hello = "world"`

Code blocks use triple backticks:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```

### Emphasis

- *Italic* with single asterisks or underscores
- **Bold** with double asterisks or underscores
- ***Bold and italic*** with triple asterisks
