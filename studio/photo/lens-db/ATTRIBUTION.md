# Lens Profile Attribution

This studio uses a minimal subset of lens correction profiles derived from the `lensfun` database.

- Project: lensfun (https://lensfun.sourceforge.io/)
- License: MIT / LGPL (profile data)
- Author: Andrew Zhilin, and contributors
- Profiles included: Canon EF, Nikon Z, Sony FE, Sigma Art, Tamron SP, Fujifilm XF, Leica M, Olympus M.Zuiko, Panasonic Lumix, Canon RF (20 profiles, subset only).

Full database available at lensfun source.
